## 📁 Estructura

```
product/
├── README.md           # Este archivo
├── requirements/       # PRDs y especificaciones
├── roadmap/            # Planificación y milestones
└── analytics/          # Métricas y KPIs
```

---

## 🎯 Responsabilidades

- Definir y documentar requisitos de producto
- Mantener el roadmap actualizado
- Crear GitHub Issues con contexto de negocio
- Medir y reportar métricas de producto
- Priorizar features basándose en valor de usuario

### Métricas
Ubicación: `analytics/[date]-metrics-report.md`
