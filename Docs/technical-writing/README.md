---

## 📋 Plantillas

### API Documentation
Ubicación: `api/[endpoint-name].md`

### User Guide
Ubicación: `guides/[feature-name]-guide.md`

### Tutorial
Ubicación: `tutorials/[topic]-tutorial.md`

Formato tutorial:
```markdown
# Tutorial: [Título]

## Qué aprenderás
- [Objetivo 1]
- [Objetivo 2]

## Prerrequisitos
- [Conocimiento previo]

## Paso 1: [Título]
[Contenido con código]

## Paso 2: [Título]
[Contenido con código]

## Próximos pasos
[Recursos adicionales]
```

---

## 📚 Estilo de Documentación

- **Claridad**: Simple > Complejo
- **Ejemplos**: Código ejecutable siempre
- **Estructura**: Progressive disclosure
- **Audiencia**: Adaptar al nivel
